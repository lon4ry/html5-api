# Каталог книг — CRUD на Fetch API

Практическая работа «Получаем и отдаём данные» по дисциплине «HTML 5 API».

Клиент на чистом JavaScript (Fetch API) работает с REST API, которое поднимает [json-server](https://github.com/typicode/json-server). Данные хранятся в `db.json`.

## Запуск

```bash
npm install
npm start
```

Открыть http://localhost:3000

## Возможности

| Операция | Метод | Запрос |
|---|---|---|
| Список книг с поиском, фильтром и сортировкой | GET | `/books?q=…&genre=…&read=…&_sort=…&_order=…` |
| Добавление книги | POST | `/books` |
| Редактирование книги | PUT | `/books/:id` |
| Отметка «прочитана» | PATCH | `/books/:id` |
| Удаление книги | DELETE | `/books/:id` |

- проверка формы (обязательные поля, год не больше текущего);
- сообщения об успешных операциях и ошибках, в том числе при недоступном сервере;
- удаление с подтверждением повторным нажатием.

## Структура

```
db.json            данные (json-server)
public/index.html  страница
public/app.js      запросы к API и отрисовка
```
