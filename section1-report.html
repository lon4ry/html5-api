Практическая работа по разделу 1. HTML5 API

1. Определения и основы

1.1. Понятие HTML5 API

HTML5 API — набор встроенных в браузер JavaScript-интерфейсов, введённых вместе со стандартом HTML5. Они позволяют веб-приложению хранить данные на клиенте, определять местоположение, работать с графикой, медиа, файлами и сетью без сторонних плагинов.

Преимущества для разработчика:

  1. Не требуются плагины (Flash, Java-апплеты).
  2. Единый стандарт для браузеров и мобильных устройств.
  3. Возможность офлайн-работы приложения.
  4. Снижение нагрузки на сервер за счёт обработки и хранения данных на клиенте.
  5. Доступ к чувствительным данным (геолокация, уведомления) только с разрешения пользователя.

1.3. Новые возможности по сравнению с предыдущими версиями HTML

  1. JavaScript API, перечисленные в п. 1.2.
  2. Семантические теги: header, nav, main, article, section, aside, footer.
  3. Встроенные audio, video, canvas, svg.
  4. Новые типы полей форм и встроенная валидация.
  5. Упрощённые DOCTYPE и указание кодировки.
  6. Клиентские хранилища объёмом в мегабайты вместо cookie (4 КБ).

Проверить поддержку в конкретном браузере можно скриптом в консоли:

const apis = {
  'Geolocation':   'geolocation' in navigator,
  'Web Storage':   typeof Storage !== 'undefined',
  'Canvas':        !!document.createElement('canvas').getContext,
  'IndexedDB':     'indexedDB' in window,
  'Web Workers':   typeof Worker !== 'undefined',
  'WebSocket':     'WebSocket' in window,
  'Drag and Drop': 'draggable' in document.createElement('div'),
  'History':       !!(window.history && history.pushState),
  'Notifications': 'Notification' in window,
  'Vibration':     'vibrate' in navigator,
  'Web Bluetooth': 'bluetooth' in navigator,
  'Battery':       'getBattery' in navigator
};
console.table(apis);

Выводы

  1. Основные API (Geolocation, Web Storage, Canvas, IndexedDB, Web Workers, WebSocket, Drag and Drop, History) поддерживаются всеми четырьмя браузерами.
  2. Chrome и Edge работают на одном движке, поэтому поддержка у них совпадает.
  3. Firefox и Safari не поддерживают Vibration, Web Bluetooth и Battery Status API.
  4. Перед использованием API следует проверять его наличие и предусматривать альтернативу.
