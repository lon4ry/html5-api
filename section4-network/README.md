# Практическая работа по разделу 4

Fetch API (JSONPlaceholder), чат на WebSocket (Socket.io) и лента постов на Server-Sent Events.

## Запуск

```bash
npm install
npm start
```

Открыть http://localhost:3030 (порт можно поменять: `PORT=4000 npm start`).

## Что реализовано

1. **Fake API и Fetch API** — выбор данных (пользователи, посты, комментарии, задачи, альбомы), фильтр по пользователю и количеству. Таймаут запроса 8 с, обработка недоступности API и ошибок HTTP (пункт «Несуществующий ресурс»).
2. **WebSocket** — чат на Socket.io: имя пользователя, сообщения в реальном времени, счётчик онлайн, уведомления о входе и выходе, подтверждение доставки (ack), автоматическое переподключение.
3. **Server-Sent Events** — эндпоинт `GET /events`. Сервер присылает новый пост каждые 10 секунд и сразу после публикации через `POST /posts`. Обрабатывается обрыв соединения и автоматическое переподключение.

## Структура

```
server.js          Express + Socket.io + SSE
public/index.html  клиент
```
